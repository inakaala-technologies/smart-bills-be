# BHive Platform Backend

This is the backend starter for the BHive modular monolith.

## Modules
- auth
- business
- customer
- billing
- payment
- document
- membership
- appointment
- notification
- reporting
- audit
- subscription
- common

## Run locally
```bash
mvn spring-boot:run
```

## Database
This project expects a MySQL instance available on localhost:3306 with a database named `bhive_db`.
